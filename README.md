# CONABREM ENTERPRISE

### Luxury Wig Store Website

A responsive e-commerce website developed for CONABREM ENTERPRISE, a wig business, featuring a luxury-inspired shopping experience with a green and gold brand identity.

## Features

- Responsive website design
- Product catalogue
- Product search and category filtering
- Wishlist / saved styles
- Product detail modals
- Customer enquiry interface
- Shopping cart and quantity management
- Checkout and order review
- WhatsApp order integration
- FAQ and customer information
- Mobile-friendly navigation and layouts

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub
